# 字幕の表示・非表示 — 研究協力者が、講義動画の下に再生位置と同期した字幕を表示し、表示・非表示を切り替えられる

## Issue

#36

## 目的(Why)

講義動画は YouTube の自動字幕しかなく、動画内に強制表示されている。自動字幕は誤認識が多く(#35 で校正中)、協力者は誤った字幕を読みながら学習することになる。校正した字幕を動画の下に表示し、見たい人だけが表示できるようにすることで、学習体験を損なわずに視聴を続けてもらう(プロダクトゴールの主指標「有効な1人分のデータ」に達する協力者の脱落を減らす)。

一方、字幕の表示・非表示の操作は研究の観測対象(視聴行動)ではない。操作が視聴ログや LAD に混ざると、研究データの解釈を損なうため、記録しない。

関連する要件: FR-70(同期表示)、FR-71(切替、記録しない)、FR-73(時刻の重なりの整理方針)。FR-72(SRT の校正)は #35(`docs/spec/srt-proofreading.md`)の範囲。

## 実現内容(What)

- 講義ページの動画の下に、字幕の表示領域と、字幕の表示・非表示を切り替えるボタンを置く。ページを開いた直後(再読み込みを含む)は、字幕を非表示にしている。
- 字幕を表示しているとき、表示領域には、動画の再生位置で有効な字幕の文を1行だけ表示する。複数のキューが有効な時間は、開始時刻が最も遅いキュー(新しい方)の文だけを表示する。再生、一時停止、スキップ、シークバーの操作に追従する。どの字幕も有効でない時間は、何も表示しない。
- 字幕の文は、ページで再生している講義の SRT(`lectures/{lecture_id}/subtitles.srt`)から取る。SRT のある全講義(lecture-1〜3)が対象。
- 動画内に YouTube 側の字幕を強制表示しない。字幕は動画の下の表示に一本化する。
- 表示・非表示の切替は、画面の見た目だけを変える。視聴ログを送らず、動画の再生状態と再生位置を変えない。切替の状態は、ページの再読み込みで初期状態(非表示)に戻る。
- AI チューターが使う SRT の文脈は、本PBIで変えない。

## 受入基準

以下、「有効な」は、キューの開始時刻 ≦ 再生位置 < 終了時刻 を指す。「表示すべき文」は、その再生位置で有効なキューのうち、開始時刻が最も遅いキュー(新しい方)の文を指す。有効なキューがなければ、表示すべき文はない(空)。

1. **字幕の表示領域と切替ボタンがある**: 講義ページを開くと、動画(シークバーと操作ボタンを含む)の下に、字幕の表示領域と、字幕の表示・非表示を切り替えるボタンが1つずつある。ボタンの文言から、押すと表示になるか非表示になるかが分かる(初期状態では、押すと表示になることが分かる文言)。〔検証: PO確認〕
2. **初期状態は非表示**: ページを開いた直後は、字幕が非表示で、表示領域に文が表示されない。動画を再生して、有効なキューがある再生位置になっても、切替ボタンを押すまで文は表示されない。〔検証: 自動テスト、PO確認〕
3. **再生中の同期**: 字幕を表示していて動画を再生しているとき、再生位置が変わってから 1 秒以内に、表示領域の文が、その再生位置の表示すべき文になる。有効なキューがない時間は、表示領域が空になる。〔検証: 自動テスト(代役のプレーヤーで再生位置を進める)、PO確認〕
4. **一時停止中**: 字幕を表示していて一時停止すると、表示領域の文は、一時停止した位置の表示すべき文のまま変わらない。〔検証: 自動テスト、PO確認〕
5. **スキップ・シークへの追従**: 字幕を表示しているとき、前後のスキップ、シークバーでの移動のあと、表示領域の文が、移動先の位置の表示すべき文になる。一時停止中のスキップ、一時停止中のシークバーのドラッグでも同じ。〔検証: 自動テスト、PO確認〕
6. **表示と非表示の切替**: 非表示のときに切替ボタンを押すと、その時点の再生位置の表示すべき文が表示される(非表示の間の再生位置の変化にも追従している)。表示のときに押すと、表示領域に文が表示されなくなる。〔検証: 自動テスト、PO確認〕
7. **切替を記録しない**: 字幕の表示・非表示を切り替えても、HTTP の要求を1件も送らない(視聴ログ `POST /api/viewing-log` を含む)。〔検証: 自動テスト(API クライアントと通信の代役で、切替の前後の送信件数が同じこと)〕
8. **切替が再生に影響しない**: 再生中・一時停止中のどちらで切り替えても、動画の再生状態(再生中/一時停止)と再生位置が変わらず、sessionStorage のキー `currenttime` の値も変わらない。切替の直後に再生・一時停止・スキップ・シークをしたとき、送られる視聴ログの件数と内容は、切替をしなかった場合と同じ。〔検証: 自動テスト〕
9. **LAD に影響しない**: 字幕を何度切り替えても、その参加者の LAD の表示内容が、切替をしなかった場合と同じ。〔検証: 自動テスト(AC7 で送信がないことにより担保する。LAD の入力は視聴ログだけ)、PO確認〕
10. **時刻の重なりの整理(新しい方の1件だけ)**: 字幕を表示しているとき、表示領域に同時に出る文は常に1件以下である。lecture-1 で、6.0 秒の時点(元のキュー2とキュー3が両方有効)では、表示領域の文はキュー3の文(現行の SRT では「が4敗ある事情であることを学んだ」)だけで、キュー2の文は表示されない。3.0 秒の時点(キュー1とキュー2が両方有効)では、キュー2の文だけが表示される。重なりのない lecture-2、lecture-3 では、各再生位置で表示される文は、元の SRT でその位置に有効なキューの文と同じ。〔検証: 自動テスト〕
11. **講義との対応**: `/lecture` で講義 X(lecture-1〜3 のいずれでも)のページを開くと、表示される字幕は `lectures/X/subtitles.srt` の内容である。別の講義の字幕は表示されない。〔検証: 自動テスト(`/lecture` の応答、またはページが受け取る字幕データで確認)〕
12. **SRT がない講義**: 表示対象の講義に SRT がない(ファイルがない、または読めない)とき、講義ページは従来どおり表示され、動画の再生、操作、視聴ログ、小テストが動く。字幕の表示領域は空のままで、エラーで画面が止まらない。〔検証: 自動テスト〕
13. **YouTube 側の字幕を強制表示しない**: 講義ページは、YouTube のプレーヤーに字幕の強制表示を求めない。YouTube の字幕の設定を変えていないブラウザで lecture-1〜3 を再生すると、動画内に字幕が表示されず、字幕は動画の下の表示領域にだけ出る。〔検証: PO確認(YouTube のプレーヤー内の表示は自動テストで観察できない)〕
14. **再読み込みで初期状態に戻る**: 字幕を表示にしてからページを再読み込みすると、字幕は非表示(AC2 の初期状態)に戻る。〔検証: 自動テスト、PO確認〕
15. **AI チューターの文脈が変わらない**: 本PBIの前後で、AI チューターのプロンプトに入る字幕の文(`interfaces/tutoring/srt.py` の結果)が変わらない。既存のテスト `tests/test_chat_lad/test_srt_in_prompt.py` が変更なしで成功する。〔検証: 自動テスト〕
16. **既存の視聴ログの回帰**: 既存のテスト(`tests/test_framework_drivers/test_lecture_player_seek_count.py` を含む `uv run pytest tests/ -v` の全体)が成功する。〔検証: 自動テスト〕

### 未解決の論点(POに確認中)

- **Q4 切替状態の保持(再読み込み時)**: 講義ページは「最初にこのページをリロードしてください」と案内しており、再読み込みが通常の操作に含まれる。本仕様の AC14 は、(a) 保持しない で書いている。POに確認中。
  - (a) 保持しない(再読み込みのたびに初期状態の非表示に戻る): 単純。表示にした後で再読み込みすると、押し直しが要る。
