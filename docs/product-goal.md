# プロダクトゴール

講義を受ける学習者が、自分の学習行動(LAD)を見ながらAIチューターと対話することで、自分の学習を振り返り、次の行動を計画できるようになる。その効果を、本研究の研究協力者を通じて検証できる状態にする。

## 補足

- 主な利用者: 本研究の研究協力者(学習者)
- 狙う変化: 自分の学習を振り返り、次の行動を計画できる
- 決定日: 2026-09-26(PO決定)。成功の指標は 2026-10-21 に追記(PO決定)。「有効」の判定を動画単位(人 × 動画)に改めた(2026-10-29、PO決定。#56 の Q6・Q15、[multi-video-learning.md](./spec/multi-video-learning.md) の6節)

## 成功の指標

プロダクトのゴールは「効果を**検証できる状態**にする」ことである。効果そのもの(振り返り、行動計画ができたか)の評価は、研究のゴールであり、プロダクトの成功指標には含めない。

**主指標: 有効な1人分のデータに達した研究協力者の人数**

| 水準 | 人数 | 意味 |
|---|---|---|
| 最低ライン | 10人 | 検証できる状態として成立する下限(期限までに確認する) |
| 満額 | 30人 | 募集の上限。登録(ID発行)は31件まで(協力者30+研究者確認用1) |

- 設計の前提: 登録30人のうち2/3が脱落しても、有効10人を確保できる。
- 期限: 2026年12月末(実験期間の終端)までに、有効10人を確認する。
- 研究協力者は、1人3本の動画を1本ずつ学習する(学習3回。1本の動画の学習を「回」と呼ぶ)。
- 「有効な1回分」(人 × 動画)の条件。1つの回(学習セッション)について、すべて満たす:
  1. その回の動画を1回でも再生した視聴イベントがある(その回の学習セッションに、`action` が `play` の視聴ログが1件以上ある。動画の準備完了の自動の再生は記録されないため、利用者が再生したことを表す。PO決定 2026-10-21、2026-10-29)
  2. その回の講義の小テストを受験している
  3. その回の対話セッションで、AI チューターとの対話が1往復以上ある(根拠は `messages`。対話ログの保存の有無は問わない)
- 「有効な1人分」の条件: その協力者の3つの回が、3つとも「有効な1回分」である(PO決定 2026-10-29)。
- 系統(理系/文系)の偏りは、指標に含めない。コンテンツ選択は、脱落率を下げるための工夫である。
- Gemini API の料金は研究室が負担するため、指標・設計の制約にしない。上限30人の根拠は、募集の見込みである。

**先行指標**(日々の確認用。成功の判定には使わない): 回ごとの、選択 → 視聴 → 小テスト → 対話 → 終了 の各段階の通過人数と、3本目の終了(全体の終了)に達した人数。
